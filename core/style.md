# 분석문구 어투·문형 (케이스탯 보고서 기준)

## 기본
- 개조식 명사형 종결: `~임`, `~나타남`, `~순임`. 서술형(~다, ~습니다)과 마침표는 쓰지 않음
- 보기는 작은따옴표 `‘ ’`, 비율은 소수 1자리 `%`, 평균은 엑셀 자릿수 + 단위(년·점)
- 짧게 쓴다. 한 문단에 수치를 너무 많이 나열하지 않는다
- 화살표(→), 주관적 수식어(매우, 압도적으로)는 쓰지 않는다
- 조사(이/가, 은/는, 을/를, 과/와, 으로/로)는 괄호를 뺀 앞말 받침에 맞춘다: `‘D-10-1(일반구직)’과`, `1.53년으로`

## 문장 속 보기·집단 이름 (표는 원문 그대로)
- `(예: …)`, `(서빙, 주방보조 등)` 같은 예시 괄호 삭제, 영문 괄호 삭제(`학사 (Bachelor's Degree)` → `학사`, `하이코리아(Hi-Korea)` → `하이코리아`)
- `A / B` 이중 표기는 앞쪽만, 끝 마침표 삭제, 긴 보기는 `--abbr`로 축약 (예: `한국어능력시험(TOPIK)` → `TOPIK`)
- 집단 이름은 괄호 앞 띄어쓰기를 뺀다: `구직비자 D-10-1(일반구직)`, `관광취업비자(H-1)`

## 가. 전체 결과 — 같은 문형이 연달아 나오지 않게 돌려 씀
| 문형 | 예시 |
|---|---|
| 기본 | `○○를 보면, ‘A’가 38.1%로 가장 높으며, ‘B’(28.4%), ‘C’(16.5%) 순임` |
| 뒤를 이음 | `○○는 ‘A’가 37.9%로 가장 많았고, ‘B’(34.9%), ‘C’(22.4%)가 뒤를 이음` |
| 2문장 | `○○를 살펴보면, ‘A’ 응답이 33.4%로 가장 높게 나타남` / `다음으로 ‘B’(25.6%), ‘C’(22.8%) 순임` |
| 비중 | `○○의 경우, ‘A’가 28.8%로 가장 큰 비중을 차지하였으며, ‘B’, ‘C’ 순으로 나타남` |
| 1위 ≥ 50% | `○○를 보면, ‘A’가 57.9%로 절반 이상을 차지함` / `이어서 ‘B’, ‘C’ 순으로 나타남` |
| 1·2위 차 < 3%p | `‘A’(27.0%)와 ‘B’(26.2%)가 비슷한 수준으로 높게 나타났으며, 그다음은 ‘C’(17.7%) 순임` |
| 보기 2개 | `‘A’가 60.5%로 ‘B’(39.5%)보다 21.0%p 높게 나타남` / `응답자 10명 중 약 7명(68.8%)이 ‘A’라고 응답함` |
| 예/아니오 여러 개 | 끝에 `‘예’ 응답을 모두 합하면 44.4%, ‘아니오’ 응답은 43.1%임` |
| 평균 | 별도 문단 `평균은 3.07년으로 나타남` |
| 요약표 | `항목별 ‘부담됨’ 비율로 보면…` / `‘문제됨’이라는 응답은 ‘A’에서 60.9%로 가장 많았음` + `반면 ‘B’는 47.7%로 상대적으로 낮게 나타남` / `모든 항목에서 ‘장벽’ 비율이 44.6~60.7% 수준으로 나타났으며, 이 중 ‘A’가 60.7%로 가장 높음` |
| 단독 척도 | `‘장벽’이라는 응답이 57.1%로 ‘장벽아님’(16.8%)을 크게 웃돎` / `‘보통’은 26.1%이며, 평균은 3.54점임` |
| 합친 하위표 | `(한국 내 대학) ‘학사’가 43.7%로 가장 높으며, …` / `(해외 대학) ‘학사’가 83.6%로 대부분을 차지하며, …` |
- 주어는 페이지 소제목, 끝의 '종합'은 뗀다. 누적·합계 수치를 쓸 때는 보기가 서로 겹치지 않는 구간인지 확인

## 나. 특성별 결과 — 사용자가 고른 구분만, 고른 순서대로 한 문단씩
**포함 기준**: 사례수 10명 미만 하위집단은 뺀다 (예: 중남미 2명, D-10-2 5명). 10~29명은 넣되 해석 주의를 사용자에게 알린다 (예: 오세아니아 28명은 넣음). 특정 집단만 보라는 지시가 없으면 모든 하위집단을 본다.

| 상황 | 문형 |
|---|---|
| 1위가 다름 → 같은 1위끼리 묶기 | `(국적) 일본·기타 아시아는 ‘TOPIK 4급’(28.0%, 36.5%), 중국은 ‘TOPIK 5~6급’(36.5%), 북미·유럽·오세아니아는 ‘TOPIK 3급’(51.9%, 34.5%, 57.1%)이 가장 높게 나타남` |
| 한두 집단만 다름 (5개 이상) | `(국적) 대부분 국적에서 ‘졸업 후 1년 이상 ~ 2년 미만’이 가장 높으나, 유럽은 ‘졸업 후 1년 미만’(34.5%)이 가장 높게 나타남` |
| 1위 모두 같음 + 2위가 다름 | `(비자유형) 두 비자 모두 ‘A’가 가장 높으나, D-10-1(일반구직)은 ‘B’(26.5%), H-1은 ‘C’(49.3%)가 다음으로 높게 나타남` |
| 1위 모두 같음 (2개 집단) | `(성별) 남성(42.9%)과 여성(53.0%) 모두 ‘A’가 가장 높게 나타남` |
| 1위 모두 같음 (3개 이상, 차이 큼) | `(연령대) 모든 연령대에서 ‘학사’가 가장 높으며, 특히 만 18~24세(86.1%)에서 높게 나타남` |
| 동률 | `북미는 ‘1년 미만’·‘1년 이상 ~ 3년 미만’(각 34.0%)` |
| 평균 표 (2개 집단) | `(성별) 평균은 남성 1.58년, 여성 1.19년으로 남성이 0.39년 더 길게 나타남` |
| 평균 표 (3개 이상) | `(국적) 평균은 중국이 1.53년으로 가장 길고, 오세아니아가 0.61년으로 가장 짧게 나타남` |
| 요약표 | `응답이` 없이 항목명에 조사: `… ‘심사 기준 불투명성’(70.6%)이 가장 높게 나타남` |
| 합친 하위표 | `(국적, 한국 내 대학) …` / 대화로 쓸 때는 `한국 내 대학은 …인 반면, 해외 대학은 …` 한 문장도 가능 |

- 모든 집단 1위가 같으면 1위만 나열하지 말고 2위나 집단 차이를 짚는다 (문장이 모두 똑같아지는 것을 피하기 위해)
- '높다/낮다' 비교는 사례수가 충분한 집단끼리만. 수치를 정확히 확인하고 사용자가 잘못 짚으면 바로잡는다 (예: "일본이 가장 높다" → 실제는 중국)
- 1·2위 차가 1%p 안팎이면 문장에서 단정하지 말고 사용자에게 알려 "비슷한 수준"으로 쓸지 묻는다

## 사용자 요청에 따른 변형 (대화로 고칠 때)
- "평균 기준으로" → 평균 문형, "상위 3개" → `중국(1.53년), 일본(1.48년), 북미(1.48년) 순으로 평균이 높게 나타남`
- "짧게" → 값 목록을 빼고 대표 집단 1~2개만: `(국적) 대부분 국적에서 ‘A’가 가장 높으나, 유럽은 ‘B’(34.5%)가 가장 높음`
- "○○는 A가 높고, △△는 골고루" → `○○는 ‘A’(93.9%)가 대부분을 차지한 반면, △△는 ‘A’(48.7%), ‘B’(35.9%), ‘C’(20.5%) 등 고르게 분포함`
