# 보고서 작업 도우미 (hwtx-report 웹 버전)

엑셀 통계표를 한글 보고서로 만들고, 그래프를 넣고, 검증까지 하는 팀 공용 웹앱입니다.
기존 hwtx-report 스킬의 스크립트를 그대로 쓰고, **분석문구 작성과 내용 검토에만 Claude API**를 붙였습니다.

| 단계 | 하는 일 | 누가 |
|---|---|---|
| 1. 파일·설정 | 엑셀·양식 한글·그래프 양식·설문지 업로드, 특성별 구분·순서, Base 풀어쓰기 | 스크립트 + AI(Base) |
| 2. 분석문구 | 표마다 가. 전체 결과 / 나. 특성별 결과 작성, 요청해서 다시 쓰기, 직접 수정 | **AI** |
| 3. 보고서·그래프 | hwpx 생성 → 그래프 PPT 생성 → (PowerPoint에서 손봄) → 300dpi 그림으로 한글에 삽입 | 스크립트 |
| 4. 검증 | 숫자 대조 + 규칙 점검 + 내용 검토, 결과 엑셀 | 스크립트 + **AI** |
| 5. 손본 보고서 문구 | 한글에서 고친 보고서의 문구만 다시 쓰기 | **AI** |

## 숫자는 AI가 만들지 않습니다
- 엑셀 값은 읽는 즉시 **엑셀식 반올림**(유효숫자 15자리 정리 → 사사오입, `xround`)으로 바꿉니다. 28.75가 28.7로 내려가던 0.1 차이 문제를 이렇게 막습니다.
- Claude에게는 이렇게 반올림한 **표시용 문자열**만 넘깁니다. Claude는 받은 값을 옮겨 쓰기만 하고 계산하지 않습니다.
- AI가 쓴 문장에 표에 없는 수치가 있으면 자동으로 한 번 고쳐 쓰게 하고, 그래도 남으면 화면에 빨갛게 표시합니다.
- 보고서를 만든 뒤 `verify.py`가 통계표 칸, 그래프 값, 문구 속 수치를 모두 엑셀과 대조합니다.

## 배포하기 (Render, 처음 한 번)

### 1) GitHub에 올리기
1. GitHub에서 새 저장소를 만듭니다. 고객사 자료는 없지만 **Private**으로 만드는 걸 권합니다.
2. 이 폴더 전체를 올립니다. 웹에서 **Add file → Upload files**로 끌어다 놓아도 됩니다.
3. `fonts/` 폴더에는 KoPub돋움체·함초롬돋움·에스코어 드림이 이미 들어 있습니다. 그래프 양식에서 다른 글꼴을 쓰면 그 파일을 더 넣으세요.

### 2) Render에서 서비스 만들기
1. https://render.com 에 GitHub 계정으로 가입합니다.
2. **New → Blueprint**를 누르고 방금 만든 저장소를 고릅니다. 저장소에 있는 `render.yaml`을 읽어서 설정이 자동으로 채워집니다.
3. 환경변수 두 개를 입력합니다.
   - `ANTHROPIC_API_KEY`: Claude API 키 (`sk-ant-…`)
   - `APP_PASSWORD`: 팀원에게 알려줄 공용 비밀번호
4. **Apply**를 누르고 5~10분 기다립니다. LibreOffice를 설치하느라 첫 빌드가 오래 걸립니다.
5. 생긴 주소(`https://hwtx-report-xxxx.onrender.com`)를 팀원에게 공유합니다.

- 요금: Starter 플랜 월 7달러 정도입니다. 무료 플랜은 15분 동안 안 쓰면 잠들고 깨는 데 1분쯤 걸려서 권하지 않습니다.
- 그래프 넣기에서 메모리 부족 오류가 나면 플랜을 Standard로 올리세요.
- 작업 파일은 서버 임시 폴더에 3일간 보관됩니다. 서버가 재시작되면 지워지니 결과물은 바로 내려받으세요.
- 코드를 고쳐서 GitHub에 다시 올리면 Render가 자동으로 다시 배포합니다.

### 내 PC에서 먼저 해 보기 (선택)
```bash
cp .env.example .env      # 키와 비밀번호 입력
./run_local.sh            # http://localhost:8000
```
그래프를 EMF로 바꾸는 기능은 LibreOffice가 설치되어 있어야 동작합니다.

### 환경변수
| 이름 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키 (서버에만 저장, 브라우저로 안 보냄) |
| `APP_PASSWORD` | 팀 공용 비밀번호. 비우면 누구나 접속 가능 (비우지 마세요) |
| `HWTX_MODEL` | 문구·검토 모델. 기본 `claude-opus-5-5` |
| `HWTX_EXTRA_RULES` | 조사별로 더할 문구 규칙 (선택) |
| `HWTX_FAKE_AI=1` | API 호출 없이 화면만 시험 (규칙 문구를 그대로 돌려줌) |

## 사용 순서

1. **파일·설정**: 엑셀과 양식 한글을 올리면 표 목록이 나옵니다. 특성별 구분을 **쓸 순서대로** 누르고, 예시 표를 고른 뒤 **설정 저장**을 누릅니다. 설문지를 올렸다면 *설문지 보고 AI가 풀어쓰기*로 Base 제안을 받고 확인합니다.
2. **분석문구**: *전체 AI 작성*을 누릅니다. 카드마다 "더 짧게", "국적은 상위 3개만" 같은 요청으로 다시 쓰거나 직접 고칠 수 있습니다. 직접 고쳤으면 *수정 저장*을 누르세요.
3. **보고서·그래프**
   - ① *한글 보고서 만들기*를 누르면 바로 숫자 대조 결과가 나옵니다.
   - ② *그래프 PPT 만들기*로 PPT를 받아 PowerPoint에서 손봅니다.
   - ③ 손본 PPT를 올리고 *그래프 넣기*를 누릅니다. 기본은 **300dpi 그림**입니다(한글에서 확인 결과 메타파일보다 예시와 같게 보임). 메타파일이 꼭 필요하면 메타파일 선택지를 고르세요.
4. **검증**: 만든 보고서나 사람이 쓴 최종본(hwpx)을 검증합니다. *숫자 대조 + 규칙 점검*을 먼저 돌리고, 이어서 *AI 내용 검토*를 돌립니다. 결과는 엑셀로 받을 수 있습니다.
5. **손본 보고서 문구**: 한글에서 고친 hwpx를 올리면 표·그래프는 그대로 두고 문구만 다시 씁니다.

## 알아 둘 점
- 그래프 그림은 슬라이드 전체가 아니라 **슬라이드 위 도형(차트·라벨 표)의 범위만** 내보냅니다. PowerPoint에서 차트를 복사해 메타파일로 붙이는 것과 같은 방식이고, 슬라이드 밖으로 넘친 긴 라벨도 잘리지 않습니다.
- 그래프는 슬라이드 노트의 `<표x-y> 제목`과 한글의 그림 캡션(그래프 박스 바로 앞 문단)으로 짝을 맞춥니다. 한쪽 제목만 고치면 짝을 못 찾습니다.
- 그래프 양식 PPT에 막대 양식 1장만 있으면 평균·척도·도넛 그래프도 막대로 만듭니다. 각 양식 슬라이드를 넣으면 기존 스킬과 같은 번호(막대 1, 도넛 12, 척도 19, 평균 45)로 씁니다.
- 줄 배치는 추정값이라, 한글에서 한 번 열어 저장하면 정리됩니다.
- 하위표를 합친 페이지는 *손본 보고서 문구*의 AI 다시 쓰기에서 빠지고, 지금 문구가 그대로 남습니다.

## 폴더 구성
```
app/        웹 서버 (main.py), AI 호출 (ai.py), 표 정리·수치 대조 (tables.py), 검증 (review.py)
core/       hwtx-report 스크립트 (build_report·build_graphs·rewrite_text·verify) + insert_graphs(EMF 삽입)
            [웹앱] 주석이 붙은 곳만 원본 스킬에서 고친 부분
static/     화면 (index.html 한 파일)
fonts/      그래프 EMF 변환용 글꼴
```
